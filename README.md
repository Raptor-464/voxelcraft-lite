# VoxelCraft Web

Browser-based multiplayer voxel sandbox inspired by Bloxd.io and Minecraft.

## Features
- Browser play on PC and mobile
- Multiplayer sync with Socket.IO
- Block placement and removal
- Inventory and hotbar
- Crafting recipes
- Top-down voxel world with player tracking
- Simple world generation

## Run locally

```bash
npm install
npm start
```

Then open:
- http://localhost:3000

## Notes
This is an original browser prototype, not a copy of Minecraft's code or textures.
